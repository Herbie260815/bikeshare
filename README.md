# Bikeshare Analysis

Python script for analysing bikeshare data from US cities
(Chicago, New York City, Washington).





\## How to run

Execute bikeshare.py with Python 3.

The script will ask you to choose a city and filters.



\## Files

\- bikeshare.py: main analysis script

\- .gitignore: excludes CSV data files from version Control





\## Dependencies

\- Python 3

\- pandas

\- numpy
